
#
- 新增一种远程仓库为端到端加密的模式
- 端到端加密模式仅指定的一个分支生效
- 远程仓库的文件全部为加密后的文件，命名规则类似为:[serial_no]-[sha256_hash]，serial_no为8位十进制序号，从00000000开始。除了00000000文件之外，其它的文件都对应一次push。
- 00000000开头的文件是manifest文件，记录了其余加密文件的基本信息：commit ID, sha256 hash。
- commit ID为当前加密文件的最新commit ID, sha256 hash表示是加密文件的哈希，也是加密文件名的第二部分(sha256_hash)
- git push／pull时，客户端与远程仓库会进行最简单的协商，但由于远程仓库无法解密文件内容，实际上是客户端的主动做了几乎全部逻辑。
- 协商实现逻辑是客户端先下载00000000开头的文件，解密后即可得到远程仓库的加密文件对应的commit ID，由此可以判断出客户端需要打包的commit范围（push）或者是需要下载的加密文件列表（pull))
